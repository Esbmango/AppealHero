# AppealHero 申诉英雄 · 比赛演示

演示使用合成罚单和模拟门户。完整录像、四张实际运行截图和封面保存在 [demo 目录](demo/)。英文参赛文案见 [Devpost 草稿](DEVPOST.md)。

## 现场准备

1. 在演示机设置 `AI_MODE=fake`、`EXEC_TIERS=T1,T2`，运行 `npm start`。需要展示浏览器操作时，可在启动前设置 `HEADLESS=false`。真实 Gemini 模式的已测范围见 [README](../README.md#verified-so-far)。
2. 打开主页，选择演示身份和界面语言。上台前在一套独立的演示数据上彩排。重复申诉同一张票时，门户可能显示它已经提交。
3. **手机演示（HTTPS）**：手机上的麦克风只在 HTTPS 下可用。第一次在 `.env` 加一行 `DEMO_KEY=…`（`sed -i '' '/^DEMO_KEY=/d' .env && echo "DEMO_KEY=$(openssl rand -hex 12)" >> .env`），终端 1 运行 `npm start`，终端 2 运行 `npm run tunnel`（需要 `brew install cloudflared`）。缺少 DEMO_KEY、或正在运行的服务没有启用它时，脚本拒绝开隧道；成功后打印带 key 的手机链接。设置 DEMO_KEY 后，电脑上也要用 `http://localhost:4000/?key=…` 打开。
   浏览器测试覆盖 320 至 1440 像素宽度、正常和改版门户。WebKit 的 iPhone 13 模拟器已走通英文工作日罚单至回执的全程。实体 iPhone 的相机、麦克风和系统授权仍需要真机验证。使用团队准备好的 HTTPS 演示地址；公开隧道前先配置 `DEMO_KEY`。
4. 录制素材使用英文界面、fake 模式和真实运行的 Playwright 浏览器。[参赛版 MP4](demo/appealhero-pitch.mp4) 为 60 秒，含英文讲解字幕和模拟回执，符合[当届 Devpost 时长要求](https://bostonhacks-2026.devpost.com/rules)。

## 可单独演示的入口

- **查票**：选择“帮我查罚单”，用 MA 车牌 `8KDW21` 查询。显示历史票和未结票；用户选择未结票后才开始调查。外州登记可改用罚单号 `900000002`。
- **个人情况**：选择工作日计时器，在个人情况中选择学生，并在陈述中说明没有收据。查看“弱”、酌情请求、费用及期限。可从补证建议上传图片。
- **凭证**：提交后打开 `/cases/<caseId>/proof`。刷新或在当前演示环境的新标签页打开，仍可读取这份记录。

## 5. 兜底方案

| 问题 | 处理 |
|---|---|
| Gemini 报错或限速 | 改用 `AI_MODE=fake` 重启（流程完全一样），并告诉评委现在是 fake 模式 |
| 隧道或网络断了 | 只用笔记本：浏览器宽度调到 1100px 以下就是手机界面 |
| 浏览器任务卡住 | 打开已完成演示案件的凭证页，展示确认号和执行轨迹 |
| 全部失败 | 播放备用视频，并说明这是之前的真实运行录像 |

## 6. 评委问答速查

**问：通用浏览器 Agent（比如 Chrome 的 auto browse）也能填表，你们有什么不同？**
答：我们做的是专门的 Agent，不是通用的。
- 每种罚单有手册，规则有官方来源，不会编造理由。
- 用户要确认两次：先确认事实，再批准申诉信。
- 批准的是签名过的内容指纹，提交前还要读回比对。
- 结果不明时先对账，绝不重复提交。
- 事后有凭证可以核验。

**问：和收费的代申诉服务比呢？**
答：有的服务按罚款比例收费（例如 Busted，具体比例演示前复核）。我们的每个案件都有成本计量：填表走确定性的 Playwright，AI 成本接近零；Computer Use 兜底接好了但演示不启用。

**问：这算不算法律服务？DoNotPay 不是出过事吗？**
答：FTC 曾对 DoNotPay 的“机器人律师”宣传采取执法行动（2024–2025 年，细节演示前复核）。我们不提供法律意见，不承诺结果，不自称律师。我们只帮用户整理事实、引用公开规则、按用户批准的内容提交。

**问：能在真实网站上用吗？**
答：比赛中只连模拟门户，执行器在网络层直接拦截真实政府域名。模拟门户的字段来自 boston.gov 公布的申诉所需信息。要接入真实门户，需要市政府或供应商许可，并且要尊重验证码；我们的适配器接口已经预留。

**问：成本多少？**
答：本次录屏使用离线模式。使用真实 Gemini 时，可从 `smoke:gemini` 的输出查看本次实测的耗时和估算费用。

**问：隐私怎么处理？**
答：演示只用合成数据；处理真实数据时使用 Gemini 付费层（免费层的数据可能被用于改进产品）；截图可以遮挡敏感字段；提交后可以删除证据。

**问：成功率多少？**
答：我们不声称申诉成功率，那由停车办公室决定。我们衡量的是流程指标：用户操作时间、提问数量、重复提交次数（目标为零）。

**问：如果 AI 编造事实怎么办？**
答：每条事实都标来源，只有用户能确认；申诉信每段必须引用已确认的事实，引用不存在就校验失败；没有核实过的规则不能自动生成理由。

**问：为什么只做停车罚单？**
答：停车罚单量大、规则清楚、可以在线申诉。RMV 的交通违章罚单是另一个机构，流程不同，申诉还要付 $25 立案费，我们只预留了接口。

## 7. 不要说的话

- “1:1 复刻官网”：应该说字段一致、外观刻意不同。
- “保证申诉成功”“AI 律师”。
- “已经在真实网站上跑通”。
- “支持所有语言”：界面是三种语言，对话可以支持更多语言。
- “已经用真实 Gemini Computer Use 验证过”：不能说，实测没通过（见上）。
- “与 Boston 市政府合作”。
